One image that sums up the world's news of Saturday 21 November 2026: 35 dated stories across 7 regions — COP31 running into overtime in Antalya, three ballistic missiles shot down over Riyadh, a magnitude 6.7 earthquake in Peru, and twenty-two more stories from Kyiv to Wellington.

The page is drawn entirely in code. A real serif face (Liberation Serif, OFL) is parsed and rasterised by the program itself — TrueType outlines, quadratic curves, scanline fill — and every picture is drawn from shapes. Nothing is copied in: no stock art, no photographs, no downloaded images.

## Run

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

Writes `out/entry.png` (1024×1024). Run it twice and the bytes are identical.
